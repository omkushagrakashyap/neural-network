# 🧠 Neural Network From Scratch (Python)

## 🚀 Overview

A fully functional **neural network built from scratch using Python and NumPy**, without relying on machine learning frameworks such as TensorFlow or PyTorch.

---

## 🚀 Features

* Fully connected feedforward neural network
* Forward propagation implementation
* Backpropagation from scratch
* Gradient descent optimization
* Custom activation functions (ReLU, Sigmoid, Tanh)
* Loss functions (MSE, Cross-Entropy)
* Multi-layer architecture support
* Training visualization (loss vs. epochs)

---

## 🛠️ Tech Stack

* **Language:** Python
* **Libraries:** NumPy, Matplotlib
* **Concepts:** Linear Algebra, Calculus, Optimization

---

## 📖 How It Works

1. Initialize weights and biases.
2. Perform forward propagation through each layer.
3. Compute the loss.
4. Apply backpropagation using the chain rule.
5. Update parameters using gradient descent.
6. Repeat the process for multiple epochs.

---

## 🧩 Core Concepts Implemented

### 1. Forward Propagation

* Matrix-based computation across layers
* Efficient vectorized implementation

### 2. Backpropagation

* Manual gradient computation using the chain rule
* Layer-wise error propagation

### 3. Optimization

* Gradient descent
* Learning rate tuning
* Convergence tracking

### 4. Activation Functions

* ReLU
* Sigmoid
* Tanh

### 5. Loss Functions

* Mean Squared Error (MSE)
* Binary and Categorical Cross-Entropy
